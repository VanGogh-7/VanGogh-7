## About

I am a mathematics student working at the intersection of mathematics and computer science, with particular interests in algebra, topology, machine learning, and AI systems. I build primarily with Rust and Python while exploring AI agents, agent runtimes, retrieval-augmented generation, distributed systems architecture, and LLM infrastructure. Linux is my daily development environment.
